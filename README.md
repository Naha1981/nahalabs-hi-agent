# HI

Business desk work, in one workspace.

Product page: https://hi.nahalabs.co.za/

## What this repository contains

- Organise tasks and conversations, prepare drafts and review proposed actions.
- Teammate, group-chat and selected-work import features from NahaLabs' earlier assistant app are merged into HI.

## Current limits

- Customer WhatsApp connection is under active change. This README does not certify customer-number delivery or unattended replies.
- External actions remain approval-gated; a model answer is not evidence that a task completed.
